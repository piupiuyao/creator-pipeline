# creator-pipeline · 达人外联全链路（轻量版）

用 **Claude Code + Gmail + Google Sheet** 跑达人合作的整条线：

> 找人 → 首触 → 跟进 → 砍价 → 合同 → 审脚本 → 付定金 → 审成片 → 发布 → 追踪效果 → 付尾款

它是平台版（网站 + 数据库 + 定时服务器）的轻量做法：
- 不用部署服务器，一个文件夹就是一个活动。
- 团队表就是 Google Sheet，邮件就在自己的 Gmail 里。
- 每天自动跑一次，出一份日报。

**机器做什么**：找人、算价、写每一封邮件、读回信、记状态、填合同、催签、追踪发布效果、写日报。

**人只做 6 件事**：

| # | 人做的事 | 在哪做 |
|---|---|---|
| 1 | 审每封邮件，点发送 | Gmail 草稿箱 |
| 2 | 锁定成交价 | 跟 Claude 说「@xx 锁价」 |
| 3 | 审脚本（通过/打回+意见） | 跟 Claude 说 |
| 4 | 付定金 | 自己付，付完跟 Claude 说 |
| 5 | 审成片 | 跟 Claude 说 |
| 6 | 付尾款 | 自己付，付完跟 Claude 说 |

## 一、整条流程

```
 ┌─ 找人 ───────────────────────────────────────────────────────────┐
 │  按关键词找  或  找相似（给几个喜欢的达人）                           │
 │  → 自动筛：粉丝范围 / 互动率≥3% / 有邮箱 / 地区 / 语言 / 排除卖课号 / 去重  │
 │  → 算价：按平均播放算公允价，首触报价 = 公允价 × 80%                   │
 └───────────────────────────────────────────────────────────────────┘
                 │  （人在团队表里看一眼，不要的标「跳过」）
                 ▼
 ┌─ 外联 ───────────────────────────────────────────────────────────┐
 │  首触 ──3 天没回──► 跟进 1 次 ──再 5 天没回──► 失联                   │
 │   │ 回信                                                            │
 │   ▼                                                                 │
 │  读回信 → 记下对方要价                                               │
 │   · 价格在范围内 → 成交待锁                                          │
 │   · 高一些 → 第 2 轮还价（最多到公允价）                               │
 │   · 高过 3 倍 → 礼貌收尾，告诉对方我们的范围                            │
 │   · 拒绝 → 礼貌收尾                                                  │
 └───────────────────────────────────────────────────────────────────┘
                 │  👤 人锁价
                 ▼
 ┌─ 履约 ───────────────────────────────────────────────────────────┐
 │  成交确认信 + 合同（+ brief）附件 ──1 天没签──► 催一次                 │
 │  → 合同签回（自动比对条款有没有被改）                                  │
 │  → 👤 审脚本：通过 → 要收款信息   /   打回 → 按你的原话写修改意见          │
 │  → 👤 付定金 → 自动写「定金已付」通知                                   │
 │  → 👤 审成片：通过 → 确认发布日期                                      │
 │  → 达人发布、回链接 → 尾款 + invoice 附件                              │
 │  → 7 天后追踪效果：播放、实际 CPM、文案有没有提到产品                     │
 │  → 👤 付尾款 → 结清                                                   │
 └───────────────────────────────────────────────────────────────────┘
                 │
                 ▼
     每天 10 点自动跑一遍，出日报：今天要你做的事 + 进展数字
```

每个人"下一步该干嘛"都由程序算，不靠 AI 判断：
- 什么时候该跟进
- 该发哪封信
- 定金、尾款各是多少

AI 只负责读懂回信、按规矩润色文字。

## 二、安装

**需要准备**

| 东西 | 用途 | 必须吗 |
|---|---|---|
| Claude Code | 跑整个流程 | 必须 |
| Node 18 及以上 | 计算程序（不用 npm install） | 必须 |
| Gmail 连接器（claude.ai → 设置 → 连接 Gmail） | 读回信、建草稿 | 必须 |
| Apify 账号和 key | 找人、追踪发布效果 | 自己有名单就不用 |
| Google Drive 连接器 | 读团队表里人改的内容 | 用 Google 表就要 |
| Claude in Chrome 浏览器插件 | 把结果写进 Google 表 | 用 Google 表就要 |
| 合同、invoice 模板（.docx），brief（可选） | 成交后随信附上 | 走到合同就要 |

**步骤**

```bash
git clone https://github.com/piupiuyao/creator-pipeline ~/.claude/skills/creator-pipeline
echo 'export APIFY_API_KEY=你的key' >> ~/.zshrc     # 需要找人才加
mkdir ~/campaigns/my-first-campaign && cd ~/campaigns/my-first-campaign
claude                                              # 然后说：set up creator-pipeline
```

第一次用时，Claude 会问清这些：
- 产品名、产品链接、一句话介绍
- 合作形式、内容要求、付款方式
- 邮件落款
- 找什么样的人：粉丝范围、地区、语言
- 用团队表的哪个 tab

**每天自动跑**（Mac）：跟 Claude 说「装每日任务」，或者自己运行下面这行：

```bash
~/.claude/skills/creator-pipeline/schedule/install-mac.sh ~/campaigns/my-first-campaign 10 0
```

## 三、日常怎么用

**你会收到**：每天 10 点一条 Mac 通知、一份日报（`reports/日期.md`），Gmail 草稿箱里还有一封「[日报]」。

日报最上面写着今天要你做的事，比如：
- Gmail 草稿箱里有 5 封等你审
- @mia 接受了 $250，等你锁价
- @leo 的脚本到了，等你审

**你只要**：
1. 打开 Gmail 草稿箱，看一遍，没问题就点发送（想改就直接在 Gmail 里改）
2. 在 Claude 里回答拍板的事，例如：

| 你说 | Claude 做 |
|---|---|
| 「找 50 个做 study with me 的 TikTok 学生博主」 | 先报计划和花费，你同意后再找 |
| 「找和 @a @b @c 相似的人」 | 同上（找相似） |
| 「@mia 锁价」/「@mia 280 成交」 | 锁价，起草成交确认 + 合同 |
| 「@leo 脚本可以」 | 起草"脚本通过，请发收款信息" |
| 「@leo 脚本要改：开头 5 秒就要展示搜索功能」 | 用你的原话起草修改意见 |
| 「@leo 定金付了，PayPal」 | 记下来，起草"定金已付"通知 |
| 「@leo 成片可以，12 月 1 号发」 | 起草"成片通过，发布日期确认" |
| 「@leo 尾款付了」 | 结清 |
| 「这几个是老合作方，再约一次」 | 首触改用"返场"的写法 |
| 「看看发布效果」 | 拉播放、算实际 CPM |

## 四、找人的两种方法

1. **按关键词找**：说出你要的人平时发什么内容，比如 "study with me"、"cold email tips"。它会搜这类视频（TikTok）或话题（IG），再找出发这些内容的人。
2. **找相似**：给 3–5 个你喜欢的达人，比如合作效果好的、品牌方点过头的。它会看这几个人最近常用哪些话题标签，自动去掉 #fyp 这种通用的，再拿这些标签去找发类似内容的人。

两种方法都过同一套筛选：
- 粉丝在设定范围内，默认 1000–5 万
- 互动率不低于 3%。复盘数据：互动率 3–10% 的达人过审率 64%，低于 1% 的只有 10%
- 有公开邮箱。简介里没有的话，会去简介里的链接页面找一次
- 简介里能看出国家的，按你设的排除地区过滤；也可以按发帖语言过滤（目前只有 TikTok 能看语言）
- 排除卖课、代运营、招学员的号，以及币圈、成人、抽奖号
- 表里已经有的人不重复加

费用参考：TikTok 一批 3 个词、看 60 个人，大约 $2；IG 更便宜。每次都先报预估花费，同意了才跑。

## 五、只用后半段（合同 → 尾款）

价格在别处谈好了、合同已经签了，或者视频已经发了，都可以从中间接进来：

1. 设置时只填落款、产品名、产品链接、内容要求、付款方式，再放好合同和 invoice 模板。找人和定价的问题可以跳过。
2. 给 Claude 一份名单，最少要有账号、姓名、平台、邮箱四列。
3. 告诉 Claude 每个人的价格和走到了哪一步，比如「@leo 200，脚本刚交上来」「@kai 500，视频已经发了」。

能接入的步骤：待发合同 / 合同已发 / 已签约 / 脚本审核 / 待付定金 / 定金已付 / 成片审核 / 待发布 / 已发布 / 尾款待付。从"定金已付"及之后接入的，默认定金已付，不会补发"定金已付"通知。

## 六、合同和 invoice 模板

用你自己的 Word 模板，在要填的地方写 `{{占位}}`，比如：

```
本协议由 {{sender_name}} 与 {{creator_name}}（{{handle}}）于 {{date}} 签订。
合作费用 USD {{amount}}，定金 {{deposit}}，尾款 {{final_amount}}。
交付内容：{{deliverables}}
达人地址：{{creator_address}}      ← 程序没有这个值，会原样留给达人填
```

可用的占位：creator_name、handle、platform、profile_url、email、amount、deposit、final_amount、date、product_name、product_url、deliverables、payment_terms、sender_name、publish_link、publish_date。

- 合同放 `templates/contract.docx`，invoice 放 `templates/invoice.docx`，brief 放 `templates/brief.pdf` 或 `.docx`。
- **没有模板就不发合同**，不会拿别家的合同顶上。
- 达人签回 .docx 后，会逐段跟你发出去的比对，条款被改了会先告诉你。

## 七、表格（Google Sheet）

- 本地的 `creators.csv` 是程序读写的那份，Google 表是团队看的那份。两边同步方式：
  - 每次运行后，Claude 用 Chrome 把整张表贴进团队表里**专门给这个流程用的那个 tab**。
  - 每次运行前，先把团队表里人改过的内容读回来。
- 团队在表里只能改三样，其他列是程序写的，改了会在下次同步时被覆盖：
  - 首触报价（发出之前）
  - 状态改成「跳过」
  - 备注

**主要的列**：
- 账号、平台、粉丝、平均播放（最近作品播放的中位数，不会被一条爆款拉高）、互动率、邮箱、地区
- 流量价值、第 1 轮报价、状态、对方要价、第 2 轮报价、成交价
- 阶段、定金已付、发布链接、发布播放、实际 CPM、提到产品、尾款已付
- 草稿（Gmail 里有待审的哪一封）、邮件记录

## 八、在不同工具里用

| 工具 | 能不能用 | 怎么用 |
|---|---|---|
| **Claude Code**（推荐） | 全部功能 | 照上面"安装" |
| **Codex（OpenAI 的命令行工具）** | 计算和流程都能用；Gmail 看有没有接好 | 在活动文件夹放一个 `AGENTS.md`，写「读 ~/.claude/skills/creator-pipeline/SKILL.md 并照做」。没接 Gmail 时，邮件存成文本文件，人复制进 Gmail；回信也由人贴给它 |
| **ChatGPT Work** | 还没验证 | 技能格式兼容（也是 SKILL.md）。但要确认两件事：能不能运行计算程序（`node cp.js help`），以及表格文件能不能隔天还在 |
| **ChatGPT 网页聊天** | 基本用不了 | 不能在你电脑上运行程序和定时任务 |

## 九、安全设计

- **机器永远不发信**：所有邮件只进 Gmail 草稿箱，由人点发送。每日自动任务连发信的权限都没有。
- **数字只来自计算程序**：价格、定金、尾款都是程序算的。AI 只读信和润色，不出价。
- **达人的来信只当信息看**：信里写什么都改不了价格和规则。遇到威胁、要全款预付、要独家、反悔加价这类情况，停下来交给人。
- **花钱前必须确认**：找人每次先报计划和费用；每日任务只允许跑追踪效果，一条大约 $0.01。
- **没有模板就不发合同和 invoice**。
- **邮件写法**：不哭穷（不写"预算有限"），不用长破折号，称呼看不清的名字一律用 "Hi there"。

## 十、和平台版比

| | 平台版（网站） | 轻量版（这个） |
|---|---|---|
| 部署 | 服务器 + 数据库 + 网页 | 一个文件夹 + Claude Code |
| 团队协作 | 多人登录、多活动、积分计费 | Google 表的一个 tab，一个活动一个文件夹 |
| 找人渠道 | Upfluence / Influencer.club / BrightData 等付费渠道 | Apify：关键词 + 找相似 |
| 补邮箱 | 7 层（含 Hunter 等付费） | 简介 + IG 商务邮箱 + 简介链接页 |
| 垂类相关性、刷量/不露脸深查 | 自动 | 人看名单把关；买量嫌疑（播放高、互动极低）自动标 |
| 发信 | 可开自动发 | 永远人点发送 |
| 收信 | 每分钟同步、自动分类 | 每天一次，Claude 读 |
| 砍价 | 按对方报价锚定（第 1 轮 80%，第 2 轮按他的价） | 按播放算公允价，先报价锚定，最多 2 轮，3 倍放弃线；5 万粉以上人定价 |
| 合同到尾款 | 全有 | 全有（同一套邮件模板和顺序） |
| 合同条款比对、发布效果追踪 | 有 | 有 |
| 按达人类型选 brief、广告授权到期提醒 | 有 | 没有（一个活动一份 brief） |

## 十一、文件

```
SKILL.md            Claude 的操作说明（主入口）
AGENTS.md           给 Codex 等其他工具的入口
cp.js               命令行：node cp.js help 看全部命令
lib/                计算程序：定价、流程、邮件模板、合同填充/比对、找人、日报、读 Google 表
reference/          细则：找人、砍价写信、履约、Gmail 和表格、每日任务
schedule/           每日定时任务（Mac）
test-*.js           测试：npm test
```

活动文件夹里会生成：
- `creators.csv`：达人表
- `pipeline.config.json`：设置
- `brief.md`：产品说明，回答达人问题只用这里的内容
- `templates/`：合同、invoice、brief 模板
- `out/`：填好的合同等附件
- `reports/`：日报
