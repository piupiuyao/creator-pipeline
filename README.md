# creator-pipeline

**Influencer marketing, automated.** 达人营销，从找人到付尾款，整条线交给 Claude 跑，人只负责拍板。

> 找人 → 首触 → 跟进 → 砍价 → 合同 → 审脚本 → 付定金 → 审成片 → 发布 → 追踪效果 → 付尾款

不用服务器，不用新平台，不用学新工具：
- 团队照样在 **Google 表**里看进度、做决定。
- 邮件照样从**自己的 Gmail** 发，每一封都由人点发送。
- 跑在 **Claude Code** 里，一个文件夹就是一个活动。

> 🧪 **Beta 版**：整条流程已在模拟的表格和 Gmail 上从头跑通，有 64 个自动测试。真实 Gmail 和 Google 表的安装还在小范围试用，遇到问题欢迎开 issue。

---

## 为什么做这个

做过达人投放的人都知道，难的不是哪一封邮件，而是同时管一百个人：
- 每个人要来回十几封信：首触、跟进、还价、合同、催签、脚本、定金、成片、尾款……谁该跟进、谁该催合同，全靠人记，一定会漏。
- 价格靠感觉谈，播放差不多的两个人，价格能差三倍。
- 表格和邮箱两头对不上：表里写着"等对方签"，其实合同早就签回来了。

creator-pipeline 把这些重复、容易出错的事都交给机器，人只在需要判断的时候出手。

## 用起来是什么样

```
你在表里 @mia 那一行写「通过」
  → 3 分钟后，Gmail 草稿箱里出现给 mia 的第一封邮件，报价已经按她的平均播放算好
你看一眼，点发送
  → 表里 mia 的「下一步」变成：已发首触，3 天没回会自动起草跟进
mia 回信："我平时收 $400"
  → Claude 读完信，按规则起草还价，放进草稿箱
mia 说 "OK, deal"
  → 自动锁价：成交确认信 + 填好名字、金额、日期的合同，一起出现在草稿箱
合同签回
  → 自动逐段比对条款，有改动先提醒你；还没发的"催签"草稿自动撤掉
……一直到发布后 7 天自动拉播放、算出实际 CPM，付完尾款发一封感谢信
```

## 机器做什么，你做什么

**机器做**：找人、按播放算价、写每一封邮件、读回信、记状态、填合同、比对合同条款、催签、追踪发布效果、写日报。

**你只做 6 件事**，都是在团队表的「你的决定」列写一句话（也可以直接跟 Claude 说）：

| # | 你做的事 | 写什么 |
|---|---|---|
| 1 | 决定联系谁，审每封邮件并点发送 | 「通过」，然后去 Gmail 草稿箱点发送 |
| 2 | 锁定成交价（对方原样接受我们的价时自动锁，不用写） | 「锁价」 |
| 3 | 审脚本 | 「脚本通过」或「脚本打回 开头 5 秒就要展示产品」 |
| 4 | 付定金 | 自己付，付完写「定金已付 PayPal」 |
| 5 | 审成片 | 「成片通过 2026-12-01」 |
| 6 | 付尾款 | 自己付，付完写「尾款已付 PayPal」 |

## 几个让人放心的设计

- **永远不替你发信。** 所有邮件只进 Gmail 草稿箱，自动任务连发信的权限都没有。
- **价格不让 AI 拍脑袋。** 报价、还价、定金、尾款都由程序按播放算；AI 只负责读懂回信、写好文字。
- **达人的信改不了规则。** 信里说什么都改不了价格和流程；遇到要全款预付、要独家、反悔加价这类情况，停下来交给人。
- **过时的草稿会自动撤掉。** 进度变了（比如对方已经签回），草稿箱里还没发的"催签"会被删掉，不会误发。
- **花钱前先问。** 每次找人前先报计划和预估花费，你同意了才跑。
- **中途也能接进来。** 价格在别处谈好了、合同已经签了，都可以从那一步开始用。

## 5 分钟上手

**需要准备**

| 东西 | 用途 | 必须吗 |
|---|---|---|
| Claude Code | 跑整个流程 | 必须 |
| Node 18 及以上 | 计算程序（不用 npm install） | 必须 |
| Gmail 连接器（claude.ai → 设置 → 连接 Gmail） | 读回信、建草稿 | 必须 |
| Apify 账号和 key | 找人（关键词 / 找相似）、追踪发布效果 | 两个找人渠道选一个或都用；自己有名单就都不用 |
| Upfluence 账号 | 找人（数据库，自带邮箱和国家） | 同上 |
| 在团队表里装「表桥」（一段 Apps Script，5 分钟） | 在表里拍板、几分钟内起草、发完自动回写进度 | 强烈建议；装不了就退回手动同步 |
| 合同、invoice 模板（.docx），brief（可选） | 成交后随信附上 | 走到合同就要 |

**步骤**

```bash
git clone https://github.com/piupiuyao/creator-pipeline ~/.claude/skills/creator-pipeline
echo 'export APIFY_API_KEY=你的key' >> ~/.zshrc     # 用 Apify 找人才加
echo 'export UPFLUENCE_USERNAME=账号 UPFLUENCE_PASSWORD=密码' >> ~/.zshrc   # 用 Upfluence 才加
mkdir -p ~/campaigns/my-first-campaign && cd ~/campaigns/my-first-campaign
claude                                              # 然后说：set up creator-pipeline
```

第一次用时，Claude 会问清这些：
- 产品名、产品链接、一句话介绍、公司名（写进合同）
- 合作形式、内容要求、付款方式
- 邮件落款
- 找什么样的人：粉丝范围、地区、语言
- 用团队表的哪个 tab，并带你装好「表桥」（见下面「表格」一节）

**装定时任务**（Mac）：跟 Claude 说「装定时任务」，或者自己运行下面这行。它会装上每天 10 点的日报；装了表桥的话，还会装上每 3 分钟一次的盯表：

```bash
~/.claude/skills/creator-pipeline/schedule/install-mac.sh ~/campaigns/my-first-campaign 10 0
```

## 整条流程

```
 ┌─ 找人 ───────────────────────────────────────────────────────────┐
 │  按关键词找  或  找相似（给几个喜欢的达人）                           │
 │  → 自动筛：粉丝范围 / 互动率≥3% / 有邮箱 / 地区 / 语言 / 排除卖课号 / 去重  │
 │  → 算价：按平均播放算公允价，首触报价 = 公允价 × 80%                   │
 └───────────────────────────────────────────────────────────────────┘
                 │  👤 人在表里审核：写「通过」或「跳过」
                 ▼
 ┌─ 外联 ───────────────────────────────────────────────────────────┐
 │  首触 ──3 天没回──► 跟进 1 次 ──再 5 天没回──► 失联                   │
 │   │ 回信                                                            │
 │   ▼                                                                 │
 │  读回信 → 记下对方要价                                               │
 │   · 接受我们的价 → 自动锁价；他报的价在范围内 → 等你锁价                  │
 │   · 高一些 → 第 2 轮还价（最多到公允价）                               │
 │   · 高过 3 倍 → 礼貌收尾，告诉对方我们的范围                            │
 │   · 拒绝 → 礼貌收尾                                                  │
 └───────────────────────────────────────────────────────────────────┘
                 │  👤 人锁价（对方原样接受我们的价时自动锁）
                 ▼
 ┌─ 履约 ───────────────────────────────────────────────────────────┐
 │  成交确认信 + 合同（+ brief）附件 ──1 天没签──► 催一次                 │
 │  → 合同签回（自动比对条款有没有被改）                                  │
 │  → 👤 审脚本：通过 → 请对方发收款信息 / 打回 → 按你的原话写修改意见       │
 │  → 👤 付定金 → 自动写「定金已付」通知                                   │
 │  → 👤 审成片：通过 → 确认发布日期                                      │
 │  → 达人发布、回链接 → 尾款 + invoice 附件                              │
 │  → 7 天后追踪效果：播放、实际 CPM、文案有没有提到产品                     │
 │  → 👤 付尾款 → 自动写「尾款已付，感谢合作」→ 结清                         │
 └───────────────────────────────────────────────────────────────────┘
                 │
                 ▼
   每 3 分钟：执行表里的决定 → 起草 → 查哪封已发出 → 把进度写回表
   进度变了、草稿箱里那封已经不该发（比如对方已签回，催签还没发）→ 自动从 Gmail 撤掉
   有达人回信 → 叫 Claude 来读（15 分钟内）
   每天 10 点：完整跑一遍，出日报
```

每个人"下一步该干嘛"都由程序算，不靠 AI 判断：什么时候该跟进、该发哪封信、定金和尾款各是多少。AI 只负责读懂回信、按规矩润色文字。

## 日常怎么用

**你会收到**：每天 10 点一条 Mac 通知、一份日报（`reports/日期.md`），Gmail 草稿箱里还有一封「[日报]」。

日报最上面写着今天要你做的事，比如：
- Gmail 草稿箱里有 5 封等你审
- @mia 报了 $250，在范围内，等你锁价
- @leo 的脚本到了，等你审

**你只要**：
1. 看表里的「下一步」列：带 👉 的是要你做的
2. 在「你的决定」列写一句话（写法见下面「表格」一节），几分钟内就会生效，「决定结果」列会显示 ✓ 成功 / ✗ 没看懂
3. 打开 Gmail 草稿箱，看一遍，没问题就点发送（想改就直接在 Gmail 里改）。发出去几分钟后，表里会自动更新到下一步

也可以直接跟 Claude 说，效果一样，例如：

| 你说 | Claude 做 |
|---|---|
| 「找 50 个做 study with me 的 TikTok 学生博主」 | 先报计划和花费，你同意后再找 |
| 「找和 @a @b @c 相似的人」 | 同上（找相似） |
| 「@mia 锁价」/「@mia 280 成交」 | 锁价，起草成交确认 + 合同 |
| 「@leo 脚本可以」 | 起草"脚本通过，请发收款信息" |
| 「@leo 脚本要改：开头 5 秒就要展示搜索功能」 | 用你的原话起草修改意见 |
| 「@leo 定金付了，PayPal」 | 记下来，起草"定金已付"通知 |
| 「@leo 成片可以，12 月 1 号发」 | 起草"成片通过，发布日期确认" |
| 「@leo 尾款付了」 | 起草"尾款已付，感谢合作"，结清 |
| 「这几个是老合作方，再约一次」 | 首触改用"返场"的写法 |
| 「看看发布效果」 | 拉播放、算实际 CPM |

## 找人：三个渠道

| 渠道 | 怎么找 | 需要 | 适合 |
|---|---|---|---|
| **关键词**（Apify） | 说出你要的人平时发什么内容，比如 "study with me"。它搜这类视频或话题，再找出发这些内容的人 | Apify key | 数据真实、便宜，什么垂类都能搜 |
| **找相似**（Apify） | 给 3–5 个你喜欢的达人。它看这几个人常用的话题标签（去掉 #fyp 这种），再拿这些标签去找类似的人 | Apify key | 照着效果好的人多找几个 |
| **Upfluence**（付费数据库） | 按关键词搜数据库 | 自己的 Upfluence 账号 | 大部分人自带邮箱和国家，也能搜 YouTube |

用 Upfluence 要注意：
- 营销、电商类关键词搜出来的，很多是卖课的号，互动率低。
- TikTok 上的人常常没有平均播放数据，这类人要你自己定价。
- 为了省额度，它先在搜索结果里免费粗筛（简介、国家、粉丝数、有没有邮箱），通过的人才拉详情。搜一页大约 2 点，拉一个人的详情大约 200 点。开始前会先告诉你剩余额度。

三个渠道都过同一套筛选：
- 粉丝在设定范围内，默认 1000–5 万
- 互动率不低于 3%。我们的复盘数据：互动率 3–10% 的达人过审率 64%，低于 1% 的只有 10%
- 有公开邮箱；没有的话，会去简介里的链接页面找一次
- 地区、发帖语言
- 排除卖课、代运营、招学员的号，以及币圈、成人、抽奖号
- 表里已有的人不重复加
- 播放很高、互动极低的，标"买量嫌疑"

找到的人进表以后，要你在表里写「通过」才会起草首触。

## 只用后半段（合同 → 尾款）

价格在别处谈好了、合同已经签了，或者视频已经发了，都可以从中间接进来：

1. 设置时只填落款、产品名、产品链接、内容要求、付款方式，再放好合同和 invoice 模板。找人和定价的问题可以跳过。
2. 给 Claude 一份名单，最少要有账号、姓名、平台、邮箱四列。
3. 告诉 Claude 每个人的价格和走到了哪一步，比如「@leo 200，脚本刚交上来」「@kai 500，视频已经发了」。

能接入的步骤：待发合同 / 合同已发 / 已签约 / 脚本审核 / 待付定金 / 定金已付 / 成片审核 / 待发布 / 已发布 / 尾款待付。从"定金已付"及之后接入的，默认定金已付，不会补发"定金已付"通知。接入后的邮件会接着你们在 Gmail 里原来的对话回。

## 合同和 invoice 模板

用你自己的 Word 模板，在要填的地方写 `{{占位}}`，比如：

```
本协议由 {{company_name}} 与 {{creator_name}}（{{handle}}）于 {{date}} 签订。
合作费用 USD {{amount}}，定金 {{deposit}}，尾款 {{final_amount}}。
交付内容：{{deliverables}}
达人地址：{{creator_address}}      ← 程序没有这个值，会换成一条空线 ________ 留给达人填
```

可用的占位：company_name（公司名，没填就用产品名）、creator_name、handle、platform、profile_url、email、amount、deposit、final_amount、date、product_name、product_url、deliverables、payment_terms、sender_name、publish_link、publish_date。程序没有值的占位一律换成空线，不会把 `{{…}}` 原样发给达人。

- 合同放 `templates/contract.docx`，invoice 放 `templates/invoice.docx`，brief 放 `templates/brief.pdf` 或 `.docx`。
- **没有模板就不发合同**，不会拿别家的合同顶上。
- 达人签回 .docx 后，会逐段跟你发出去的比对，条款被改了会先告诉你。

## 表格（Google Sheet）：在表里拍板

团队表就是操作台：
1. 你在表里写一句决定。
2. 几分钟内，邮件就进了 Gmail 草稿箱。
3. 你在 Gmail 点发送。
4. 几分钟内，表里自动更新到下一步。

**怎么接上（装一次，约 5 分钟）**：
1. 在团队表里打开「扩展程序 → Apps Script」，粘贴 `sheet/bridge.gs`。
2. 在左边「服务」里加上 Gmail API。
3. 运行一次 `setup`，按提示授权，从日志里抄下口令。
4. 部署成网页应用（以「我」的身份执行，「任何人」都可以访问）。
5. 把网址和口令填进设置文件。

详细步骤见 `reference/sheet-bridge.md`，Claude 也会一步步带你做。以后更新了 `bridge.gs`，要在 Apps Script 里「管理部署 → 新版本」重新发布一次。

这段脚本只能做这些事：
- 读写这张表
- 在你的 Gmail 里建草稿（不能发信），以及删掉它自己建的、已经过时的草稿
- 查某封草稿还在不在、发出去没有
- 查达人有没有新来信（只看时间，不看正文）

**表里的前四列**：

| 列 | 谁写 | 是什么 |
|---|---|---|
| 账号 | 都可以 | 你也可以直接在表里加一行新达人（至少填账号、平台、邮箱），会自动收进来 |
| 你的决定 | 你写 | 一句话，执行完自动清空 |
| 决定结果 | 机器写 | ✓ 已执行 / ✗ 没看懂或不能执行（原话保留，你改一下就行）/ ⏳ 等 Claude 处理 / 🗑 撤掉了过时草稿 |
| 下一步 | 机器写 | 用大白话写这个人下一步是什么；带 👉 的是要你做的 |

**「你的决定」的写法**：

| 写 | 效果 |
|---|---|
| 通过 / 跳过 | 审核：要不要联系这个人（「通过了」「ok」「✅」也认） |
| 通过 200 | 按 200 美元通过。没有粉丝/播放数据、5 万粉以上这类机器不出价的人，就这样写 |
| 报价 200 | 只改首触报价、先不通过（发出之前） |
| 锁价 / 锁价 280 | 锁定成交价，起草成交确认 + 合同（对方原样接受我们的价时会自动锁，不用写） |
| 接手 已签约 300 | 从中间某一步接进来 |
| 签了 | 合同签回了 |
| 收到脚本 / 不审脚本 | 脚本到了 / 这单不审脚本 |
| 脚本通过 / 脚本打回 意见 | 中文意见会由 Claude 翻成英文再起草 |
| 定金已付 PayPal | 起草"定金已付"通知 |
| 收到成片 / 成片通过 2026-12-01 / 成片打回 意见 | 审成片 |
| 发布 https://… | 起草尾款 + invoice |
| 尾款已付 PayPal | 起草"尾款已付，感谢合作"，结清 |
| 重写 | 你删了草稿，想重新起草 |
| 暂停 / 取消 / 恢复 阶段 | |

**多快**：
- 表里拍板，到 Gmail 出现草稿：3 分钟内。
- Gmail 发出，到表里更新：3 分钟内。
- 达人回信后，Claude 读完并记好：最多约 15 分钟，下一封草稿在接下来的 3 分钟内出来。
- 电脑要开着；合上盖子的话，打开后会自动补上。

**其他说明**：
- 写错了不会乱执行：「决定结果」会写 ✗，并告诉你这一行现在该写什么。
- 除了「你的决定」和备注，其他列都是机器写的，手改会在下一轮被覆盖。
- 装不了表桥（比如公司 Google 管理员不允许"任何人"访问的网页应用）的话，就退回手动同步：Claude 每次运行时用 Chrome 把表贴回去。这样没法做到几分钟内更新。

## 在不同工具里用

| 工具 | 能不能用 | 怎么用 |
|---|---|---|
| **Claude Code**（推荐） | 全部功能 | 照上面"5 分钟上手" |
| **Codex（OpenAI 的命令行工具）** | 计算和流程都能用；Gmail 看有没有接好 | 在活动文件夹放一个 `AGENTS.md`，写「读 ~/.claude/skills/creator-pipeline/SKILL.md 并照做」。没接 Gmail 时，邮件存成文本文件，人复制进 Gmail；回信也由人贴给它 |
| **ChatGPT Work** | 还没验证 | 技能格式兼容（也是 SKILL.md）。但要确认两件事：能不能运行计算程序（`node cp.js help`），以及表格文件能不能隔天还在 |
| **ChatGPT 网页聊天** | 基本用不了 | 不能在你电脑上运行程序和定时任务 |

## 目前做不到的

- **不会自动发信**：这是故意的，每封都要人点发送。
- **定时任务只支持 Mac**，电脑要开着。
- **一个活动一份 brief**，不按达人类型自动换 brief。
- **5 万粉以上的达人由人定价**，机器只给参考。
- **垂类是否对口、是否刷量**：只有"买量嫌疑"自动标出，其余要人看名单把关。
- **邮件写法有固定的规矩**：不哭穷（不写"预算有限"），不用长破折号，看不清名字的一律称呼 "Hi there"。想换风格可以改 `lib/templates.js`。

## 文件

```
SKILL.md            Claude 的操作说明（主入口）
AGENTS.md           给 Codex 等其他工具的入口
cp.js               命令行：node cp.js help 看全部命令
lib/                计算程序：定价、流程、邮件模板、合同填充/比对、找人、日报、读 Google 表
reference/          细则：找人、砍价写信、履约、Gmail 和表格、每日任务
schedule/           定时任务（Mac）：每日日报 + 每 3 分钟盯表
sheet/bridge.gs     装进 Google 表的表桥脚本
test-*.js           测试：npm test
```

活动文件夹里会生成：
- `creators.csv`：达人表
- `pipeline.config.json`：设置（含表桥口令，不要分享）
- `brief.md`：产品说明，回答达人问题只用这里的内容
- `templates/`：合同、invoice、brief 模板
- `out/`：填好的合同等附件
- `reports/`：日报
